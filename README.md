## The epitaph

> Here lies Joe. He said he'd be back in five minutes. It's been forty years.

One line, 75 characters. A tombstone for everyone who ever said "five minutes" — the punch lands in the last words: forty years later, he's still not back.

## How it works

`main.ts` writes the epitaph to `/output/entry.txt`. Run it with Node 22:
